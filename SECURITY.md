# Security Policy

ClearLane is pre-release and does not yet have supported release versions.

Please do **not** open a public issue for a suspected security vulnerability. Use GitHub's private vulnerability reporting for this repository when available. If that is unavailable, contact the maintainer privately through their GitHub profile.

Include enough information to reproduce and assess the issue, but do not include secrets, credentials, private browsing data, or unrelated personal information.

Security-sensitive areas include CEF/Chromium sandboxing, permissions, downloads/files, external protocols, JavaScript/native bridges, DevTools exposure, Shields request handling, and future agent-control endpoints.
